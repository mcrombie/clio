# Clio adviser portraits

Generated with the built-in image-generation tool for the original Sula, Tavo, Yara and Lian characters. These production game assets are embedded into the desktop executable. Each image was generated separately; no pre-existing character portrait was edited. The exact prompts below record the generated art direction.

Clear face, three-quarter portrait facing slightly to the viewer's right.
